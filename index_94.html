⚙️ Configuración inicial

Datos en Google Sheets — acceso simultáneo desde varias PCs. Se configura una sola vez.

1 — Crear la hoja
sheets.new → copiar el ID de la URL:
spreadsheets/d/[ID]/edit
2 — Apps Script
Extensiones → Apps Script → pegar el código → guardar.
3 — Publicar
Implementar → Nueva implementación → Web App
Ejecutar como: Yo · Acceso: Cualquiera → copiar URL.
